TL;DR — One MoE backbone serving many agents should not use one expert mask. DEP reads each agent's system prompt and task input and predicts a specialized expert mask for it in a single small forward pass, with no per-workflow calibration.

Same backbone, same 50% retention, same calibration data — only the serving setting changes. Static masks (REAP, NAEE) that track the dense model for a single agent lose much of that accuracy on a multi-agent workflow over the same tasks, ending up below the single agent they were meant to improve on. A mask chosen per agent does not.

Abstract

Mixture-of-Experts (MoE) architectures scale language models efficiently by activating only a few experts per token, but the saving is confined to computation: every expert must stay resident on the accelerator, so memory bounds where these models can be deployed. Expert pruning reduces this footprint, yet existing methods are static — a single mask, calibrated offline, is applied to the model for every subsequent request. This assumption can fail when the workload is heterogeneous, most prominently in multi-agent systems, where one backbone serves many tasks and roles at once: our analysis shows that different tasks and roles recruit different experts, while static methods assign one fixed subset to all of them. We therefore propose Dynamic Expert Pruning (DEP), which rests on a finding we establish here: an agent's system and task prompts are by themselves sufficient to identify the experts that agent and its task require, since that text already describes what the agent will do. A lightweight predictor, trained once on workflow transcripts, turns those prompts into a specialized per-request mask in a single forward pass, with no per-configuration calibration. Across diverse tasks and roles, model scales, and MoE architectures, DEP achieves better overall accuracy than static pruning and merging baselines, and generalizes to workflows unseen in training without retraining. Its margin over those baselines is largest when few experts are retained, suggesting that the role specialization inherent to multi-agent systems permits sparser serving than static pruning allows.

Why Static Masks Fail

We segment agent outputs into nine discourse operators (Framing, Planning, Deriving, Computing, Concluding, Judging, Describing, Reviewing, Testing) to describe behavior independently of agent identity. Three facts follow: different agents generate different operators, different operators route to different experts (2.2–19× a permutation null, $p \le .006$), and so different agents use different experts. A prefill control shows the prompt acts by changing what the agent writes, and what it writes determines where it routes — so the prompt already carries what is needed to anticipate an agent's experts before generation begins.

Method

One-shot mask prediction. A small predictor $f_\theta$ (a Qwen2-0.5B encoder plus an MLP head) reads the concatenated agent system prompt and task input and outputs per-layer expert scores $S \in \mathbb{R}^{L \times E}$; the mask keeps the top-$K$ experts in every layer:

$$m_{\ell e} = \mathbf{1}\!\left[ S_{\ell e} \ge \tau_K(S_\ell) \right], \qquad \textstyle\sum_e m_{\ell e} = K \;\; \forall \ell .$$

The mask is installed at the router of the frozen backbone (masked logits set to $-\infty$), so per-token top-$k$ routing runs unchanged inside the kept set and model weights are untouched. Because the predictor conditions on prompt text rather than a roster identifier, any new agent or workflow gets a mask in one shot.

Training. The predictor is trained once on transcripts of the dense backbone running the training workflows, mixing two signals: an impact-coverage target (per-example REAP saliency, binarized at top-$K$, with BCE) that says which experts mattered, and self-distillation that measures what a candidate mask breaks, using a temperature-annealed soft top-$K$:

$$\mathcal{L} = \alpha\, \frac{1}{|\mathcal{R}|}\sum_{t \in \mathcal{R}} \mathrm{KL}\!\left(P_{\mathcal{M}}(\cdot \mid x_{<t}) \,\Vert\, P_{\mathcal{M}\odot\tilde m}(\cdot \mid x_{<t})\right) + (1-\alpha)\,\mathrm{BCE}\big(\sigma(S),\, m^\star\big).$$

Serving with delta loading. Only the $K$ kept experts per layer are resident, so memory shrinks nearly in proportion to the retention $\rho = K/E$. Masks are cached by $(p_a, q)$; at an agent hand-off the engine copies only the experts that differ between consecutive masks, and the next agent's delta can be prefetched because the workflow topology is known in advance.

Accuracy–memory frontier. DEP holds accuracy at footprints where both static masks have already collapsed, and reconverges with them only at mild compression, where pruning is nearly free for everyone. A wrong mask does not just answer worse — it degenerates into repetition up to the generation cap, so DEP also finishes faster end-to-end despite paying for expert swaps.

Generalization, Scale, and Architecture

Unseen workflows. One universal predictor, trained on a pool of 32 discovered workflows over three tasks and then frozen, is evaluated on a ladder of increasing distance from training: unseen workflow structures, an unseen workflow family, unseen benchmarks (SVAMP, MBPP) and an unseen domain (MMLU). With no retraining or recalibration, DEP is the strongest policy on most rungs at both retentions. Expert merging (HC-SMoE) stays competitive while the budget is loose but collapses at 25%; REAP remains competitive on code.
